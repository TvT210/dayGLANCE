# 📱 手机访问考研日历 PWA · 3 种方案

> **场景**：你想在手机上查看/勾选考研日历的"🎯 目标"和"今日任务"
> **当前状态**（2026-09-10）：新版 PWA 已部署到 GitHub Pages，手机直接访问即可

---

## ✅ 方案 1：直接访问 GitHub Pages（推荐）

**适用**：任意时间、任意网络

**步骤**：
1. 手机 Chrome / Safari 打开: **`https://tvt210.github.io/dayGLANCE/pwa/app.html`**
2. 等待页面加载（首次 ~5 秒，要下载 1MB JS）
3. 看到 4 个主 tab（📅日历 / 🎯目标 / 📚资料 / 🤖AI）
4. **加到主屏**：
   - **Android Chrome**: 菜单 (⋮) → "添加到主屏幕" → 命名"考研日历" → 添加
   - **iOS Safari**: 分享按钮 (↑) → "添加到主屏幕" → 命名"考研日历" → 添加
5. 从主屏图标打开 → 全屏体验，像原生 app

**优点**：
- 任何网络都能用（4G/WiFi/校园网）
- 加到主屏 = 离线可用（Service Worker 缓存）
- 自动同步（你电脑改了 app.html，重新部署后手机打开就是新版本）

**注意事项**：
- iOS PWA 通知受限（只能用应用内提醒，不能 push）
- Android PWA 通知可用
- API key 存在手机本地 IndexedDB（不外传）

## 🏠 方案 2：局域网（最快，0 网络依赖）

**适用**：在家/宿舍，手机电脑同 WiFi

**步骤**：
1. **电脑**（Windows）：
   ```
   双击 D:\考研\07_学习计划\启动本地服务.bat
   ```
   弹出 PowerShell 窗口，会自动：
   - 起 HTTP 服务 (端口 8765)
   - 用 Chrome PWA 模式打开 http://localhost:8765/app.html

2. **电脑**查局域网 IP：
   ```
   Win+R → 输入 cmd → 回车
   ipconfig
   找 "IPv4 地址"，比如 192.168.1.100
   ```

3. **手机**连同一 WiFi，访问：
   ```
   http://192.168.1.100:8765/app.html
   ```
   （把 IP 替换成你电脑实际的）

4. 手机加到主屏（跟方案 1 一样）

**优点**：
- **完全离线也能用**（不依赖外网）
- 速度最快（局域网）
- 调试方便（改完即时刷新）

**缺点**：
- 离开 WiFi 就连不上
- 电脑必须一直开着
- 每次电脑 IP 可能变（路由 DHCP）

## 🌐 方案 3：ngrok 公网穿透（任何网络）

**适用**：不在家/想给同学演示/手机用 4G 也要访问本地

**前置**：
```powershell
# 安装 ngrok（一次性）
choco install ngrok   # 如果有 choco
# 或去 https://ngrok.com/download 手动下载
```

**步骤**：
1. 电脑跑 `启动本地服务.bat`（或单独起 HTTP 服务）
2. 另开一个 PowerShell：
   ```
   ngrok http 8765
   ```
3. ngrok 给一个 URL（类似 `https://abc123.ngrok.io`）
4. 手机访问 `https://abc123.ngrok.io/app.html`

**优点**：
- 任何网络（4G/校园网/外网）都能访问
- HTTPS 加密
- 不用部署到 GitHub

**缺点**：
- 免费版 URL 每次启动都变
- 免费版限流量（1GB/月）
- 电脑必须开着

## 🆘 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| GitHub Pages 打开 404 | 还没部署完 | 等 5-10 分钟再试，清浏览器缓存 |
| 打开是空白 | Service Worker 缓存了旧版 | 浏览器设置 → 清除站点数据 → 重新打开 |
| 主屏图标打不开 | iOS Safari 限制 | 删了从 Safari 重新"添加到主屏幕" |
| AI 报错 "网络错误" | MiniMax 接口问题 | 重试；或换 DeepSeek/Ollama preset |
| 局域网连不上 | 防火墙拦了 8765 端口 | 控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建 → 端口 8765 |
| 局域网 IP 不对 | WiFi 切换过 | `ipconfig` 重查 |

## 🔄 怎么更新 PWA（你改了 app.html 后）

**方案 1（推荐）**：
1. 修改 `D:\考研\07_学习计划\app.html`（或同目录其他文件）
2. 跑这个 PowerShell 一行命令推 GitHub：
   ```powershell
   Copy-Item -Force D:\考研\07_学习计划\app.html D:\kaoyan-dayglance\pwa\app.html
   Set-Location D:\kaoyan-dayglance
   git add pwa/app.html
   git commit -m "update PWA"
   git push origin main
   ```
3. 等 2-5 分钟，手机下次打开就是新版本

**方案 2**：在 `D:\考研\07_学习计划\` 跑 `启动本地服务.bat`，手机直接访问局域网 URL
