## 4. 🎯 目标模块使用（新功能，重点看）

### 4.1 添加长期目标

1. 切到 "🎯 目标" 标签
2. 点顶部对应 agent 的 "+" 按钮（+ 📗 数学 / + 📘 英语...）
3. 填：
   - 标题（例：12 月模考数学 130+）
   - 目标值 + 单位（例：130 分）
   - 当前值（默认 0）
   - 截止日期
4. 保存

### 4.2 一键导入默认任务

在 "今日任务" 卡片下面点 **"📋 默认模板"**：

- 一次性导入 6 个 agent 的 22 条默认每日任务
- 基础期通用，阶段调整时改 `app.html` 里 `DEFAULT_TASKS` 对象
- 每次勾选任务 → 自动累加到对应目标的进度

### 4.3 关联任务

每个目标卡片下面有 "+ 任务" 按钮：

- 输入任务标题
- 输入完成数（每次勾选给目标加多少进度）
- 任务自动归到今日
- 勾选 → 进度条自动 +N

### 4.4 手动改进度

目标卡片 "📝 改进度" 按钮 → 输入新当前值。适用于：
- 模考后录入分数
- 大量词汇背完后批量更新

### 4.5 快速独立任务

不挂目标的任务（如"整理错题本"）直接在 "今日任务" 下面输入框 + 添加。

## 5. 🤖 6 Agent AI 切换

AI 标签顶部 7 个 tab（通用 + 6 agent）：

| Agent | 职责 | 自动 prompt 特色 |
|---|---|---|
| 🤖 通用 | 任何问题 | 含院校/偏好/阶段的全量背景 |
| 📘 英语 | 词汇/阅读/写作/真题 | 强调"具体词数/篇数/时长" |
| 📕 政治 | 1000题/肖四/时政 | 强调"题号/章节/时长" |
| 📗 数学 | 高数/线代/概率/真题 | 强调"章节/视频/题号" |
| 📙 专业课 | 408 数据结构/计组/OS/计网 | 强调"科目/章节/题号" |

## 8. 故障排查

| 问题 | 解决 |
|---|---|
| 打开白屏 | 硬刷 (Ctrl+Shift+R) / 清缓存 / 重新安装 PWA |
| AI 报错 "网络错误" | 检查 baseUrl / apiKey；MiniMax 国内端点偶有波动，重试 |
| AI 输出有奇怪符号 | **已修复**。如果还出现，发我截图 |
| 任务勾不上 | 浏览器 IndexedDB 写满 (罕见)；导出资料 → 清除数据 → 重做 |
| 部署到公网后 key 被盗 | **不要部署到公网！** PWA 应该本地用，key 永远不外传 |
