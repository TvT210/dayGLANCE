## 一、核心思想

**v1 文档是"时间块导向"**——告诉你每天该学几个小时。**v2 改成"目标导向"**——

- 每个 agent（英语/政治/数学/专业课/健身/健康）有独立的**长期目标**（12 月模考分数 / 词汇量 / 体重）
- 每个目标有**阶段产出**（基础/强化/冲刺，每月应该达到什么程度）
- 每天从**默认任务模板**出发，勾选完成自动累加进度
- AI 6 个 agent 专家负责答疑、调整、监控

**为什么不只搞时间块**：时间块告诉你"坐在图书馆 3h"，但你可能发呆 1h。**目标告诉你"今天必须做对 20 道高数题"**——结果是可量化的，过程你自己优化（坐 1.5h 做完 20 题就 OK）。

## 八、app.html PWA 配套

| 功能 | 用法 |
|---|---|
| 📋 默认模板 | 每天开机点一次，导入 22 条默认任务 |
| ✓ 勾选任务 | 完成任务后点左侧方框，进度自动累加到对应目标 |
| 📝 改进度 | 模考后录入分数、整月词汇量更新等 |
| 🤖 6 agent | 切到对应 agent 问具体问题（带专属 prompt 约束） |
| 📅 日历 | 月/周/日视图看课表 + 考研时间块 + 健身 + 家教 |

**与计划文档的关系**：
- 计划文档 = 战略（每月该完成什么）
- app.html = 战术（每天勾什么 / 问什么）
- AI 6 agent = 顾问（哪里卡了 / 怎么调整）
